## Skills Progression Map

This repository is structured to progress through:

* Layer 2 switching ✅
* VLAN segmentation
* Inter-VLAN routing
* Static and dynamic routing
* Network security, including ACLs
* Network services, including DHCP and NAT
* IPv6 fundamentals
